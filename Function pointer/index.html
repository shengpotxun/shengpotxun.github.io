what is function pointer?

First, it is a pointer. If you don’t know what is a pointer, you have to relearn the basic knowledge of C.

Usually, a data pointer points the data stored in Stack(RAM), while the function pointer points the start of executable code in Flash/ROM.

In the context of embedded systems, you can think of a function pointer as a “stored jump address.”

When you compile your code, the compiler and linker assign every function a specific address in the Flash memory (the Code Segment). A Function Pointer holds the address of the first instruction of a function in Flash.

When you “call” a function pointer, the CPU’s Program Counter (PC)—the register that tracks which instruction to execute next—is updated to that “entrance” address.Then it will fall into the function.

How to use a function pointer

There are three tips to define a function pointer.

  • Match the return type: void
  • Wrap the pointer name in parentheses with an asterisk: (*func_ptr)
  • Match the arguments: (int)
