deploy and edit

github page

create [username].github.io repository. This can auto create a page for your blog.

Then we need a plugin to push all your htmls to this repository.

  • Step one: npm install hexo-deployer-git --save point these code in you blog root directory.
  • Step two: Add the code below to the end of _config.ymlwhich is also in your blog’s root directory.

after all, you can runnpx hexo g -d to deploy your blog. You can see the page after about 1min using the url “username.github.io”

push all your config

we can create another repository to manage all configs for your blog.It is not different from managing any other project,but you should remember that thers is no need to push all htmls again.

So we can touch a new .gitignore

use obsidian to write markdown

You can use obsdian to edit markdown. But these is some problems.

  • need to bind hexo/source/_post with obsidian
  • the format of hexo pictures is different from obsidian
  • the format of obsidian inside link can not be recgnized by hexo
  • any new essay should be added some Front-matter otherwise it will no be generated as hexe’s essay.

bind the soft link between hexo and obsidian

ln -s /your/Obsidian/BlogPosts /your/Hexo/source/_posts

Don’t forget linking attachments with images

ln -s [ObsidianPath]/images [HexoPath]/source/images

the picture link format

First, open obsidian -> setting -> files and links -> default location for new attachments: int the folder specified below -> Attachments folder path: images

Now, all the attachments will be saved in /images. But we still need to change the link format to Path from vault folder.

At this time, if you try to paste a photo(example.png) from clipboard, you will find that the link is “images/example.png“. However, this format is still no supported by hexo, it need the absolute path .So the right path must be “![](/images/exameple.png)“

So we can write a script to add \ for every picture path.

Make a new directory called script under the root diectory of hexo,and touch a script fix-image-path.js

fix the inside link of obsidian

The default format of the link in hexo is setted in _config.yml.

This will make everything in a mess.We need to change it to a simple format.

At this time, if you try to runnpx hexo g s to check the url, you will find every url still have a prefix before the title of notes, for example, /Hexoblog/your note's title/.That’s because I use soft link and bind the obsidian directory Hexoblog under hexo’s _post directory. I wirte a script flatten-url.js to solve this problem(still put it in script directory).

OK, and then we need to make some changes to obsidian.In a simple word, we need to change every note link in obsidian though a scriptfix-obsidian-link.js. This script will detect all links and rewrite it in a right way which can be recgnized by hexo.

add right front-matter for all new notes

If you are familar with obsidian, you maybe know the great plugin Templater. We can make some usefull templates, but remenber to put all templates on the directory called _templates. The folder whose name’s first latter is _ will not generated by hexo as normal notes.
